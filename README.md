# Мониторинг макроэкономических новостей России

Веб-приложение для автоматического сбора и просмотра макроэкономических
новостей, касающихся России, из официальных и проверенных источников.

**Стек:** Python 3.11+ · FastAPI · SQLite · APScheduler · ванильный JS-фронтенд.

## Источники данных

| Источник | Канал | `verified` |
|---|---|---|
| Банк России | RSS: пресс-релизы + события (`cbr.ru/rss/RssPress`, `cbr.ru/rss/eventrss`) | ✓ первоисточник |
| Банк России | официальные курсы валют (`cbr.ru/scripts/XML_daily.asp`) — 1 запись в день | ✓ первоисточник |
| Росстат | RSS `rosstat.gov.ru/rss` (см. примечание о сертификате) + официальная лента ведомства на портале Правительства РФ (`government.ru/department/456/events/rss/`) | ✓ первоисточник |
| Минфин России | RSS пресс-центра (`minfin.gov.ru/rss_news?mod=news`) | ✓ первоисточник |
| ТАСС | общая RSS-лента, отбирается только рубрика «Экономика и бизнес» с макроэкономическими маркерами | информагентство |
| Интерфакс | общая RSS-лента, отбирается только экономический блок с макроэкономическими маркерами | информагентство |

Поле `verified = true` означает официальный первоисточник (госорган / ЦБ);
для информагентств `verified = false`, при этом каждая запись всегда содержит
ссылку на оригинал.

**Reuters** прекратил публикацию публичных RSS-лент в 2020 году. При наличии
лицензированной ленты её можно подключить без изменения кода — см.
`EXTRA_RSS_SOURCES` ниже.

## Быстрый старт

```bash
pip install -r requirements.txt
python run.py
# интерфейс: http://localhost:8000
```

При старте сервера сразу выполняется первый цикл сбора, далее — автоматически
каждые 7 минут (настраивается, допустимый по ТЗ диапазон 5–10 минут).

Разовый сбор без сервера:

```bash
python -m app.collect             # все источники
python -m app.collect cbr_press   # один коллектор
```

Тесты:

```bash
python -m pytest tests/
```

## Архитектура

```
app/
├── config.py        # настройки (переопределяются переменными окружения)
├── db.py            # схема SQLite и запросы
├── rss.py           # парсер RSS 2.0 (stdlib, без внешних зависимостей)
├── categorizer.py   # рубрикация по ключевым словам + фильтр релевантности
├── collectors/      # по одному модулю на источник (base.py — общий код)
├── scheduler.py     # APScheduler: периодический сбор
├── collect.py       # CLI разового сбора
└── main.py          # FastAPI: REST API + раздача фронтенда
frontend/            # index.html + app.js + style.css (без сборки)
data/                # news.db (создаётся автоматически, в git не попадает)
```

### Схема БД

```sql
news_items (
    id           INTEGER PRIMARY KEY,
    title        TEXT NOT NULL,
    summary      TEXT,
    source       TEXT NOT NULL,      -- cbr | rosstat | minfin | tass | interfax
    url          TEXT NOT NULL,      -- ссылка на первоисточник
    published_at TEXT NOT NULL,      -- ISO 8601, UTC
    collected_at TEXT NOT NULL,      -- ISO 8601, UTC
    category     TEXT NOT NULL,      -- ставка ЦБ | инфляция | ВВП | курс валют | ...
    verified     INTEGER NOT NULL,   -- 1 = официальный первоисточник
    dedup_hash   TEXT UNIQUE         -- SHA-256(нормализованный заголовок + дата)
)
collection_runs (...)                -- журнал запусков сбора для индикатора обновления
```

Дедупликация: перед сохранением считается SHA-256 от нормализованного
заголовка (регистр, пробелы, «ё») и даты публикации; UNIQUE-ограничение в БД
гарантирует отсутствие дубликатов даже при параллельных запусках.

Категории: `ставка ЦБ`, `инфляция`, `ВВП`, `курс валют`, `санкции`, `резервы`,
`бюджет и налоги`, `банковский сектор`, `финансовые рынки`, `прочее`.
Правила — в `app/categorizer.py`.

## REST API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/news` | лента с фильтрами: `source`, `category`, `date_from`, `date_to`, `q`, `limit`, `offset` |
| GET | `/api/meta` | источники, категории, время последнего обновления, журнал запусков |
| POST | `/api/collect` | ручной запуск сбора (кнопка «Обновить сейчас») |

## Настройка (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `COLLECT_INTERVAL_MINUTES` | `7` | период сбора (по ТЗ 5–10 минут) |
| `DB_PATH` | `data/news.db` | путь к SQLite-базе |
| `PORT` / `HOST` | `8000` / `0.0.0.0` | адрес сервера |
| `DISABLED_SOURCES` | — | отключить источники: `tass,interfax` |
| `EXTRA_RSS_SOURCES` | — | JSON-список дополнительных RSS-лент: `[{"id":"reuters","title":"Reuters","url":"https://…","verified":false}]` |
| `EXTRA_CA_FILE` | — | дополнительный CA-сертификат (PEM), см. ниже |
| `DISABLE_SCHEDULER` | — | `1` — не запускать планировщик (для тестов) |

### Сертификат для rosstat.gov.ru

Сайт Росстата использует TLS-сертификат, выпущенный УЦ «Russian Trusted Root
CA» (Минцифры России), которого нет в стандартных хранилищах доверия. Чтобы
прямая лента Росстата работала, скачайте официальный корневой сертификат
(публикуется на Госуслугах) и укажите путь к PEM-файлу:

```bash
EXTRA_CA_FILE=/path/to/russian_trusted_root_ca.pem python run.py
```

Сертификат объединяется со стандартным бандлом — проверка TLS не отключается.
Пока прямая лента недоступна, коллектор Росстата автоматически использует
официальную ленту ведомства на портале Правительства РФ.

## Интерфейс

- лента новостей с сортировкой по дате публикации (свежее — выше);
- фильтры по источнику, категории, диапазону дат + полнотекстовый поиск;
- индикатор времени последнего обновления (подсвечивается, если сбор давно
  не выполнялся) и кнопка ручного запуска сбора;
- у каждой записи — ссылка на первоисточник и отметка «✓» для официальных
  источников;
- тёмная тема по системной настройке.
